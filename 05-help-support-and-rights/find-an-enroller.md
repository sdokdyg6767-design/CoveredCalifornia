# Find an Enroller

- **Source URL:** https://www.coveredca.com/get-help/find-an-enroller
- **Covered California section:** Get Help
- **Retrieved:** 2026-10-13

## Summary

This page is the entry point to the Covered California certified enroller (certified enrollment counselor) and licensed insurance agent locator. It lists the four kinds of free help an enroller provides and directs consumers to a searchable tool showing enrollers and storefronts near them. The locator itself is a client-side interactive map; its result fields and labels are documented below from the page's own interface copy.

## Key Facts

- Enroller help is **free** in all four listed categories.
- Enrollers provide: **Help Selecting a Plan**, **Application Assistance**, **Financial Help Estimates**, and **Help in Your Language**.
- Only **certified enrollers and agents** are listed in the locator.
- Each enroller profile distinguishes a **Licensed Insurance Agent** from a counselor.
- Results also cover **Covered California Storefronts**.
- Profiles show **Languages Spoken** and **Office Hours**, with statuses such as **Open Now**, **Closed**, **See all Hours**, **Hide Hours**, and a **Call for hours** fallback where no hours are published.
- Each result provides **View Details**, **Get Directions** and a **Call** action.

## Details

### What Enrollers Help With

The page presents four badges, each marked **Free**:

| Service | Description |
| --- | --- |
| Help Selecting a Plan | Free help choosing between available plans |
| Application Assistance | Free help completing the Covered California application |
| Financial Help Estimates | Free help estimating the financial help you qualify for |
| Help in Your Language | Free help from an enroller who speaks your language |

### Locator Interface Labels

The locator on this page is an interactive, client-side tool. The interface copy captured from the page defines the following labels and states:

| Element | Labels and values |
| --- | --- |
| Result action | View Details / View details for {name}{city} |
| Open state | Open |
| Closed state | Closed |
| Hours fallback | Call for hours |
| Provider type | Licensed Insurance Agent; counselor |
| Location type | Covered California Storefronts |
| Languages | Languages Spoken |
| Hours | Office Hours, Open Now, Closed, See all Hours, Hide Hours, and "Call for hours" where no office hours are listed |
| Day label | Today |
| Directions | Get Directions |

### Certification

Only **certified enrollers and agents** are listed in the tool. If you are unsure whether someone is certified, call the Covered California Service Center at **(800) 300-1506**. Covered California's consumer protection guidance also advises recording an enroller's name, certification number, phone number, address and organisation website if you accept their help.
