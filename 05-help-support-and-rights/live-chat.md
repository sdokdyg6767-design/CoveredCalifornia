# Live Chat

- **Source URL:** https://www.coveredca.com/get-help/live-chat
- **Covered California section:** Get Help
- **Retrieved:** 2026-10-13

## Summary

This page hosts the Covered California live chat widget, letting a consumer chat online with a support representative. The page itself is deliberately minimal — its entire static content is the chat interface — because the conversation UI, its availability status and the transcript are all created at runtime in the browser.

## Key Facts

- Live chat is one of the three headline free help channels on Covered California, alongside the **(800) 300-1506** phone line and in-person certified enroller help.
- The chat widget is rendered client-side; no chat hours are published in the page's static HTML.
- The Service Center phone remains the alternative when chat is unavailable: **(800) 300-1506**, TTY **(888) 889-4500**.
- Service Center phone hours are **Monday to Friday, 8 A.M. to 6 P.M.**; **Saturday and Sunday closed**.

## Details

### What This Page Provides

The page title is "Chat with a member of our support team." Its static body contains only the chat container — no scripted transcript, no FAQ list, and no published availability window. Chat availability status is displayed inside the widget itself once the page loads.

### How It Fits With Other Help Channels

Covered California describes live chat as one of three ways to get **free** help:

| Channel | Access |
| --- | --- |
| Live Chat | Chat online with a Covered California representative for help with your questions |
| Phone | Call **(800) 300-1506** — available in multiple languages, TTY **(888) 889-4500** |
| In person | Find Free Local Help — certified enrollers and agents near you, in multiple languages |

### Fallback If Chat Is Unavailable

Because the chat widget publishes no service hours in the page source, use the phone line for guaranteed access during Service Center hours, **Monday to Friday 8 A.M. to 6 P.M.**, weekends closed. For TTY callers the number is **(888) 889-4500**. For issues that need independent escalation after the Service Center cannot resolve them, see the Ombuds Office page.

### Retrieval Note

Content on this page is generated at runtime by a JavaScript chat client. The static HTML yields only the page heading and standard site chrome; the chat transcript, agent greetings and availability messages are not present in the server-rendered document and therefore cannot be captured in an offline reference record.
